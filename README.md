# WebApp

Небольшое клиент-серверное приложение для решения прикладных математических задач. Состоит из двух частей:

- **serverdiploma** — серверная часть;
- **testdip** — клиентская часть;

## Статус проекта

Проект **работоспособен**, но сейчас идёт активная доработка:

- код разбивается на отдельные модули (математика, сеть и т.д.);
- вводится более чёткая структура заголовочных и исходных файлов;
- улучшается читаемость и поддерживаемость.

Запуск клиента (хранится в testdip, написан в PHP) осуществлялся через xampp: перемещаем в папку htdocs, затем запуск Apache в контрольной панеле, переходим по localhost/testdip.

Запуск сервера (написан на C++): можно выгрузить с репозитория в последних версиях VS и скомпилировать (или иными способами). Сервер запускается по localhost, клиент также слушает localhost.
