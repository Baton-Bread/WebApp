# WebApp

Небольшое клиент-серверное приложение, написанное на C++ в учебных целях
(дипломный проект). Состоит из двух частей:

- **serverdiploma** — серверная часть;
- **testdip** — клиентская часть;

## Статус проекта

Проект **работоспособен**, но в текущем виде написан **небрежно**: часть кода
сгенерирована с помощью ИИ, структура файлов неоднородная, а некоторые
участки требуют рефакторинга и приведения к единому стилю.

Сейчас идёт активная доработка:

- код разбивается на отдельные модули (математика, сеть и т.д.);
- вводится более чёткая структура заголовочных и исходных файлов;
- улучшается читаемость и поддерживаемость.

Проект все еще в работе.
